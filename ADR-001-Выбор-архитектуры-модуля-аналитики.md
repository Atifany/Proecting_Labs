# ADR-001: Асинхронная аналитика на RabbitMQ и ClickHouse<br>
**Контекст:**<br>
Необходимо собирать события интернет-магазина и формировать отчёты без существенного влияния на работу сайта.<br>

**Альтернативы:**<br>
1) Синхронная запись в основную БД.<br>
2) RabbitMQ и отдельное хранилище ClickHouse.<br>
3) Сторонняя SaaS-платформа аналитики.<br>

**Решение:**<br>
Выбран вариант 2: события передаются через RabbitMQ, обработчик записывает их в ClickHouse, API отчётов читает данные из ClickHouse.<br>

**Обоснование:**
Производительность - ключевой пункт достигается вынесением обработчика в отдельный сервис, не добавляя существенной нагрузки на существующие сервисы.<br>
Уменьшение связности - разделение операционной и аналитической нагрузки<br>
Гибкость - независимое масштабирование компонентов<br>
Отказоустойчивость - отключение любого из добавленых компонентов никак не сказывается на работе основных сервисов.<br>

**Последствия:**<br>
- Производительность не затронута.<br>
- Аналитическая нагрузка вынесена из основной БД.<br>
- Данные доступны с задержкой: производительность достигается ценой немгновенной согласованности.<br>
- Масштабируемость достигается созданием дополнительных компонентов и увеличеснием сложности сопровождения.<br>
