## ADR-001: Асинхронная аналитика на RabbitMQ и ClickHouse<br>
# Контекст:<br>
Необходимо собирать события интернет-магазина и формировать отчёты без существенного влияния на работу сайта.<br>
<br>
# Альтернативы:<br>
1) Синхронная запись в основную БД.<br>
2) RabbitMQ и отдельное хранилище ClickHouse.<br>
3) Сторонняя SaaS-платформа аналитики.<br>
<br>
# Решение:<br>
Выбран вариант 2: события передаются через RabbitMQ, обработчик пакетно записывает их в ClickHouse, API отчётов читает данные из ClickHouse.<br>
<br>
Причины: разделение операционной и аналитической нагрузки, независимое масштабирование компонентов<br>
<br>
# Последствия:<br>
- Аналитическая нагрузка вынесена из основной БД.<br>
- Данные доступны с задержкой: производительность достигается ценой немгновенной согласованности.<br>
- Масштабируемость достигается созданием дополнительных компонентов и увеличеснием сложности сопровождения.<br>
