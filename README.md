# Лабораторная работа №1

Компонентная диаграмма модуля аналитики включает ключевые сервисы в следующем алгоритмичном порядке:
1) WEB-приложение c модулем сбора событий ассинхронно отправляет собранную статистику с сайта в rabbitMQ.
2) RabbitMQ пересылает сообщения в агрегатор событий, который подготавливает данные к записи в базу данных и записывает их.
3) ClickHouse хранит аналитические данные.
4) API аналитики по необходимости берет данные из ClickHouse и формирует отчёты.
5) Дашборд показывает удобный отчет с возможностью загрузки для аналитиков (целевой пользователь модуля аналитики)
